Unified Modeling Language (UML)

UML on standardne visuaalne keel tarkvarasüsteemide struktuuri ja käitumise planeerimiseks ning dokumenteerimiseks.

Use Case | Class | Sequence | State | Activity | Component

Spetsiifilised diagrammid väljaspool indeksit:

  • UML > ERD Diagramm - Andmebaaside struktuur
  • UML > Flowchart (Vooskeem) - Protsesside loogika

1. Use Case Diagram (Kasutuslugu)

Kirjeldus: Näitab süsteemi funktsionaalsust lõppkasutaja vaatenurgast ehk mida süsteem teha võimaldab.

Elemendid: Actor (kasutaja/väline süsteem), Use Case (ovaalne tegevus), Joon (seos osaleja ja tegevuse vahel).

[Kasutaja] --------> ( Lisa toode ostukorvi )

2. Class Diagram (Klassidiagramm)

Kirjeldus: Süsteemi struktuurne mudel, mis näitab klasse, nende andmeid (atribuudid) ja funktsioone (meetodid).

Elemendid: Kolmeks jagatud kast (Nimi, Atribuudid, Meetodid), tühja otsaga nool (pärilus ehk inheritance).

+-----------------------+
|        Kasutaja       |
+-----------------------+
| - kasutajanimi: String|
+-----------------------+
| + logiSisse(): void   |
+-----------------------+

3. Sequence Diagram (Järjestusdiagramm)

Kirjeldus: Näitab objektide ja komponentide vahelist suhtlust kronoloogilises ehk ajalises järjestuses.

Elemendid: Lifeline (katkendjoon, mis näitab objekti aega), pidev joon (päring/tegevus), katkendjoon (vastus).

Kasutaja           Veebileht
   |                   |
   |--- logiSisse() -->|
   |<-- Edukas/Viga ---|

4. State Diagram (Olekudiagramm)

Kirjeldus: Kirjeldab ühe kindla objekti elutsüklit, selle võimalikke olekuid ja sündmusi, mis olekut muudavad.

Elemendid: Ring (algus/lõpp), ümar ristkülik (olek), nool (üleminek koos sündmusega).

(Algus) --> [ Konto ootel ] --(Kinnita meil)--> [ Konto aktiivne ]

5. Activity Diagram (Tegevusdiagramm)

Kirjeldus: Dünaamiline diagramm, mis näitab süsteemi tegevuste ja sammude voogu (sarnane vooskeemile).

Elemendid: Ümar kast (tegevus), romb (otsustuskoht/tingimus hargnevate teedega Jah/Ei).

[ Ava äpp ] --> { Kas logitud? } --Jah--> [ Kuva sisu ]
                       |
                      Ei --> [ Kuva sisselogimine ]

6. Component Diagram (Komponendidiagramm)

Kirjeldus: Struktuurikomponentide diagramm, mis näitab koodimoodulite, API-de või andmebaaside vahelisi tehnilisi sõltuvusi.

Elemendid: Kast (komponent/moodul), nool (sõltuvus ehk liides teise komponendiga).

[ Kliendiliides ] --(REST API)--> [ Maksete moodul ]

Ainemapi osad:

  • ERD diagramm
  • Flowchart (Vooskeem)
